# 세대차 (세대통역 라디오)

출퇴근길에 영어 회화를 듣듯, **차 안에서 요즘말과 그때말을 귀로 배우는 세대 공감 오디오 클래스**입니다. Pleos Connect 차량용 앱입니다.
차속·기어·방향지시등 같은 **주행 데이터가 클래스의 진행자**입니다. 출발하면 클래스가 시작되고, 신호 대기 때 퀴즈를 내고, 운전에 집중해야 할 때는 스스로 멈춥니다.

> **운전 1번 = 클래스 1회, 도착 = 복습, 달린 거리 = 진도**

앱 이름 '세대차'는 세대 차이를 좁혀 주는 차(車)라는 뜻입니다. 서버 없이 차량 안에서 모두 처리하고, 학습 기록은 차량에만 저장합니다.

## APK 파일

- 위치: [`apk/드라이브테일_세대차_release.apk`](apk/드라이브테일_세대차_release.apk) (약 11MB, 2026-11-12 출품 준비 버전)
- 바로 받기: [APK 다운로드](https://github.com/Park8407s/SedaeCha/raw/master/apk/%EB%93%9C%EB%9D%BC%EC%9D%B4%EB%B8%8C%ED%85%8C%EC%9D%BC_%EC%84%B8%EB%8C%80%EC%B0%A8_release.apk)
- release 빌드입니다. 공모전 제출용이라 디버그 키로 서명했습니다.
- 코드 줄이기(R8)를 켜고 내장 음성을 AAC(m4a)로 압축해 77MB → 약 11MB 로 줄였습니다. 그중 내장 음성이 약 7MB 입니다. 아래 '음성'을 참고하세요.

## 실행 방법

1. Pleos Connect 에뮬레이터를 켭니다.
2. APK 를 설치합니다. 아래 두 방법 중 하나를 쓰면 됩니다.
   - **방법 A. adb 명령** (권장): `-g` 는 차량 권한(차속 등)과 알림 권한을 설치할 때 한 번에 허용합니다.

     ```bash
     adb install -r -g "apk/드라이브테일_세대차_release.apk"
     ```

   - **방법 B. 끌어다 놓기**: APK 파일을 에뮬레이터 화면 위로 드래그해서 놓으면 설치됩니다.
     이때는 권한이 자동으로 허용되지 않습니다. **앱을 처음 실행할 때 뜨는 권한 요청을 모두 '허용'** 해 주세요.
     차속 권한은 '위치 정보에 액세스' 요청으로 표시됩니다. 허용하지 않으면 차속을 받지 못해 신호 대기·정체를 판단하지 못합니다.
3. 하단 독(앱 목록)에서 **세대차** 아이콘(라디오 전파)을 누릅니다.
4. 앱을 한 번 열면 백그라운드에서 클래스 대기를 시작합니다. 이후 다른 앱으로 화면을 바꿔도, 기어를 D로 바꾸면 클래스가 소리로 시작됩니다.
   - 시동(부팅) 때 자동으로 켜지지 않습니다. 출발 전에 세대차를 한 번 열어 주세요.
   - 완전히 끄려면 설정 → **세대차 끄기**를 누릅니다. 다시 열면 다시 켜집니다.
5. 짧게 확인하려면 아래 '심사용 데모 사용법'을 참고하세요. 출품 빌드는 데모 모드가 기본입니다.

## 동작 방식

```
주차 중(P)   방향 고르기 (요즘말 / 그때말 / 섞어서), 예상 주행 시간으로 오늘의 말 편성
기어 D       클래스 시작 → 인트로 → 예정 시각마다 말 코너 (화면 없이 소리로만)
주행 중      신호 대기 → 듣기 퀴즈 / 정체 → 덤 코너 / 깜빡이·급가감속·내비 안내 → 잠시 멈춤
P + 차속 0   마무리 멘트 → 도착 화면 (오늘 배운 말, 써먹기 미션) → 복습 퀴즈 → 내 말모음
```

코너가 시작될 때만 오디오 포커스(`AUDIOFOCUS_GAIN_TRANSIENT`)를 가져오고, 끝나면 돌려줍니다. 그래서 코너 사이에는 원래 듣던 음악·라디오가 이어집니다.

### 판단 기준

| 항목 | 기본 모드 | 데모 모드 |
|---|---|---|
| 신호 대기 | 차속 0 이 3초 이상 | 같음 |
| 정체 | 30km/h 미만 60초 연속 | 30km/h 미만 **20초** 연속 |
| 급가속 / 급제동 | 1초 사이 +10km/h 이상 / −14km/h 이상 | 같음 |
| 급가속·급제동 뒤 재개 | 10초 | 같음 |
| 방향지시등 꺼진 뒤 재개 | 1초 | 같음 |
| 퀴즈 | 생각 시간 5초, 직전 퀴즈 후 60초, 같은 말은 한 클래스에 2번까지 | 같음 |
| 말 개수 | 예상 주행 10분 미만 2개 / 10~30분 3개 + 덤 / 30분 이상 5개 + 덤 | 3개 + 덤 고정 |
| 테마 팩 | 기본 팩 처음부터, SNS·사진 300km, 음악·아이돌 500km | 모두 열림 |

급가속·급제동 기준은 국토교통부·한국교통안전공단 '위험운전행동 판별 기준(2022)' 중 승용차에 가장 가까운 택시 기준입니다.
모든 수치는 [`core/Rules.kt`](app/src/main/java/com/kumhoht/sedaecha/core/Rules.kt) 한 곳에 있습니다.

### 겹칠 때 우선순위

내비 음성 안내 → 급가속·급제동 → 방향지시등 → 기어 R·N → 신호 대기 퀴즈 → 정체 덤 코너 → 말 코너

앞의 넷은 '멈춤 조건'입니다. 진행 중인 코너를 멈추고, 풀리면 **멈춘 문장의 처음부터** 이어 갑니다.

- 정차 중(차속 0)에 켠 방향지시등은 무시합니다. 좌회전 대기 중에도 퀴즈를 낼 수 있습니다.
- 퀴즈 중에 출발하면 생각 시간을 건너뛰고 정답만 들려줍니다. 이때 방향지시등이 켜져 있으면 정답도 생략합니다.
- 말 코너 도중 정차하면 말을 끝까지 들려준 뒤, 여전히 정차 중이면 퀴즈를 냅니다.

### 개발 명세에 없어 정한 것

- **신호 대기는 정체 시간을 다시 셉니다.** 차속 0 이 3초 이상 이어지면 정체로 세지 않습니다. 그대로 세면 가상 출근길 37~58초 정차가 정체로 잡혀 덤 코너가 엉뚱한 때 나옵니다.
- **급가감속은 최근 1초 창 안에서 가장 오래된 값과 비교합니다.** 차속은 100ms 마다 읽습니다. Virtual Console 의 차속이 약 1초 간격의 계단식이라, 1초보다 오래된 값과 비교하면 계단 두 칸이 한꺼번에 잡혀 보통 가속도 급가속이 됩니다.
- **데모 모드로 직접 운전할 때는 3분 기준으로 말 간격을 나눕니다.** 데모 모드는 예상 주행 시간을 쓰지 않으므로, Virtual Console 약 3분 시연에 맞췄습니다.

## 사용 방법

주행 중(기어 D·R)에는 플랫폼이 앱 화면을 가리고, 주차하면 다시 보입니다. 모든 화면은 주차 중에만 씁니다.

| 화면 | 할 수 있는 것 |
|---|---|
| 홈 | 오늘의 클래스 미리 보기(예상 시간·말 목록·덤 코너), 배우는 방향 고르기(저장됨), 세대 공감 레벨, 지난 클래스 말 다시 듣기, 심사용 데모 입구, 설정 |
| 도착 | 클래스가 끝나면 자동으로 열림. 말 카드(뜻·그때말 짝), 급제동 때 듣던 말 다시 듣기, 운행 요약(신호 대기 퀴즈 수·자동 멈춤 횟수), 써먹기 미션 |
| 복습 퀴즈 | 이번 클래스에서 들은 말 4지선다 (최대 5문제, 다시 듣기 표시된 말 먼저). 맞히면 다시 듣기 해제, 틀리면 표시 |
| 내 말모음 | 요즘말 / 그때말 / 다시 듣기 탭. 항목을 누르면 다시 들려주고, 끝까지 들으면 다시 듣기 표시가 사라짐. 세대 공감 레벨, 함께 달린 거리와 테마 팩 |
| 심사용 데모 | 가상 주행 재생 (아래 '심사용 데모 사용법') |
| 설정 | 클래스 편성(기본/데모 모드), 말하기 속도(천천히 0.85 / 보통 0.95 / 빠르게 1.05) + 미리 듣기, 음성 상태, 학습 기록 초기화, 세대차 끄기 |

- **세대 공감 레벨**: 배운 말 개수로 올라갑니다. 낯선 말(0~9) → 알아듣기(10~24) → 맞장구(25~49) → 세대 통역사(50 이상).
- **배운 말**은 설명을 끝까지 들은 말만 셉니다. 도착이나 시간 부족으로 끝까지 듣지 못한 말은 다음 운행 첫 순서로 편성합니다.
- **말 고르는 순서**: 지난번 못 들은 말 → 안 배운 말 중 쉬운 말부터(같은 난이도면 세대 격차가 큰 말 먼저) → 다시 듣기 말 → 오래전에 배운 말.
- **학습 기록 초기화**와 **세대차 끄기**는 확인 창을 거쳐 실행됩니다. 세대차를 끄면 TTS·차량 데이터 수신과 백그라운드 서비스까지 멈춥니다(학습 기록은 유지).

### 기본 모드 / 데모 모드 (설정 → 클래스 편성)

> **출품 빌드는 시연 시간에 맞춰 데모 모드가 기본으로 켜져 있습니다.** 실제 서비스 기준으로 확인하려면 설정에서 기본 모드로 바꿔 주세요.

| 모드 | 편성 | 정체 판단 | 테마 팩 |
|---|---|---|---|
| 기본 모드 | 최근 같은 시간대(±1시간) 운행 5번의 평균 주행 시간 (기록이 없으면 15분) | 1분 | 달린 거리만큼 열림 |
| 데모 모드 | 말 3개 + 덤 코너 고정, 3분 기준 간격 | 20초 | 모두 열림 |

## 심사용 데모 사용법

> 심사·시연용 기능입니다. 실제 서비스에서는 제외하거나 첫 실행 시 미리 듣기로 축소할 수 있습니다.

**운전 없이 확인하기 (가상 주행)**
1. 홈 오른쪽 위 **심사용 · 가상 주행으로 들어 보기**.
2. **처음부터**: 저장된 17분 출근길(15.0km)을 3분 10초로 압축한 1초 단위 기록(차속·기어·방향지시등)을 실제 차량 신호 대신 넣어 재생합니다. 판단 로직은 실제 주행과 같습니다.
3. 진행 바, 차량 속도·기어·방향지시등, 지금 일어나는 일(예: '클래스 잠시 멈춤 · 말 2 ‘중꺾마’ 설명 중')이 화면에 표시됩니다. 실제 차량에서는 주행 중에 화면이 보이지 않습니다.
4. **장면 바로 가기**: 신호 대기 · 듣기 퀴즈(34초), 정체 · 덤 코너(115초), 급제동 · 즉시 멈춤(140초), 도착 · 도착 화면(186초)으로 바로 이동합니다. 그 시점 이전의 말은 들은 것으로 처리합니다.
5. 끝나면 도착 화면이 **샘플**로 표시됩니다. 데모 결과는 내 말모음·레벨·거리에 저장하지 않습니다.

| 시점 | 차량 데이터 | 클래스 동작 |
|---|---|---|
| 0:00 | 출발 (기어 D) | 클래스 시작, 인트로 |
| 0:08 | 일반 주행 | 말 1 ‘킹받다’ |
| 0:41 | 신호 대기 (37초부터 정차) | 듣기 퀴즈 ‘킹받다’ |
| 1:00 | 출발 | 말 2 ‘중꺾마’ |
| 1:15 | 우측 방향지시등 5초 | 설명 멈춤, 꺼지면 멈춘 문장 처음부터 |
| 2:00 | 정체 20초 (1:40부터 20km/h 안팎) | 덤 코너 ‘요즘 문화 한 스푼’ |
| 2:20 | 정체 풀림 | 말 3 ‘럭키비키’ |
| 2:28 | 급제동 (1초에 −17km/h) | 즉시 멈춤, 10초 뒤 '이어서 들을게요', ‘럭키비키’ 다시 듣기 표시 |
| 2:53 | 신호 대기 | 듣기 퀴즈 ‘럭키비키’ (다시 듣기 우선) |
| 3:08 | 도착 (기어 P) | 마무리 후 도착 화면 |

- 데모는 출품 빌드 전용입니다. `app/build.gradle.kts` 의 `DEMO_ENABLED` 를 `false` 로 빌드하면 데모 입구가 사라지고, 설정 기본값이 기본 모드가 됩니다.

**Virtual Console 로 직접 운전하기**
1. 설정 → 클래스 편성이 **데모 모드**인지 확인합니다 (출품 빌드 기본값).
2. 홈에서 배우는 방향을 고릅니다.
3. Virtual Console: Emulation Controls → Gear Selection **D** → **ACCEL** 로 출발, **BRAKE** 로 정차, 깜빡이는 `turn` 검색 → Blink left/right. 기어를 D 로 바꾸면 앱 화면이 내려가고 클래스가 소리로 시작됩니다.
4. 0km/h 로 세우고 Gear **P** → 마무리 멘트 뒤 도착 화면이 열립니다.

- Virtual Console 페달은 누름/뗌만 있어 가감속이 고정(ACCEL 약 +18, BRAKE 약 −44 km/h/s)입니다. 그래서 길게 밟으면 급가속·급제동으로 판정돼 10초씩 멈춥니다. 부드러운 운전으로 시연하려면 **페달을 0.5초 정도씩 짧게 끊어 누르세요.** 판정 기준은 실차와 같게 두었습니다.
- 페달 없이 일정한 가감속으로 시험하려면 [`tools/drive_scenario.sh`](tools/drive_scenario.sh) 를 쓰세요. Virtual Console 의 HTTP API 로 약 3분 동안 출발 → 신호 대기 → 깜빡이 → 정체 → 급제동 → 신호 대기 → 도착을 운전합니다. Virtual Console 웹 페이지는 닫아 두세요. 열려 있으면 D 기어의 크리프 속도가 섞입니다.

  ```bash
  adb forward tcp:8088 tcp:8088
  bash tools/drive_scenario.sh
  adb logcat -s ClassRunner SpeechPlayer Telemetry
  ```

## 음성

- 기본은 안드로이드 `TextToSpeech`(ko-KR)로 콘텐츠 팩의 문장 단위 음성 스크립트(`voice_sentences`)를 앱 안에서 바로 읽습니다. 문장 사이는 0.4초 쉽니다.
- **Pleos Connect 에뮬레이터(v2.1.0)에는 쓸 수 있는 안드로이드 TTS 엔진이 없습니다.** 하나 있는 Pleos 음성 서비스는 초기화에 실패합니다(Pleos TextToSpeech SDK 는 공모전 기간에 쓸 수 없음). 그래서 개발 명세 7의 대비책을 구현했습니다.
  - [`tools/gen_voice.ps1`](tools/gen_voice.ps1) 이 개발 PC 의 Windows 한국어 음성(Microsoft Heami)으로 같은 스크립트를 문장별 음성 357개로 미리 변환해 `app/src/main/assets/voice/` 에 넣습니다. 인트로처럼 바뀌는 문장은 경우의 수(출근길·퇴근길·운전길 × 요즘말·그때말·말 × 0~5개)만큼 만듭니다. 만든 WAV 는 [`tools/compress_voice.ps1`](tools/compress_voice.ps1) 이 Windows 기본 AAC 인코더로 m4a(16kHz mono 32kbps)로 압축합니다 (45MB → 약 7MB, 추가 설치 없음).
  - 앱은 기기 TTS 를 쓸 수 없으면 자동으로 이 파일을 재생합니다(설정 › 음성 상태: '내장 음성 사용 중'). 말하기 속도는 재생 속도로 맞춥니다.
  - 콘텐츠 팩 JSON 을 고치면 스크립트를 다시 실행해야 합니다.

    ```powershell
    powershell -ExecutionPolicy Bypass -File tools\gen_voice.ps1
    ```

## 콘텐츠 팩

- `app/src/main/assets/sedae_radio_content_pack_v0.5.json`: 요즘말 28개(문장 단위 음성 스크립트·퀴즈), 그때말 모드 17개, 요즘 문화 카드 3개, 제외 12개(제외 사유 기록), 공통 안내 멘트
- `app/src/main/assets/sedae_demo_drive_log_v2.json`: 가상 출근길 190초 (1초 단위 차속·기어·방향지시등, 장면별 이벤트)
- 특정 집단을 비하하는 신조어나 혐오 표현은 수록하지 않습니다. 뜻·예문·음성 스크립트·퀴즈는 기사 문장을 옮기지 않고 직접 작성했습니다. 출처는 각 항목의 `source` 에 있습니다.
- 팩 추가 = 데이터 추가입니다. 같은 형식의 항목을 넣으면 편성·퀴즈에 바로 쓰입니다.

## 안전·개인정보

- 주행 중에는 앱 화면과 헤드업 알림을 쓰지 않고 소리로만 진행하며, 어떤 입력도 요구하지 않습니다. 상태 알림은 소리·진동이 없는 알림 하나만 씁니다.
- 방향지시등·급가속·급제동·내비 안내 때는 클래스가 먼저 물러납니다.
- 학습 기록과 주행 요약은 차량 로컬 DB 에만 저장하고 서버로 보내지 않습니다.
